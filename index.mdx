WSTG-Scan is a comprehensive, interactive penetration testing tool built for pentesters and bug bounty hunters. It implements the [OWASP Web Security Testing Guide (WSTG)](https://owasp.org/www-project-web-security-testing-guide/) and [OWASP API Security Top 10](https://owasp.org/API-Security/) methodology in a single Python script — covering everything from reconnaissance and directory fuzzing to advanced injection testing, WordPress attacks, Active Directory pentesting, and exportable HTML dashboards.

## What WSTG-Scan Does

WSTG-Scan orchestrates industry-standard tools (Nuclei, Nmap, ffuf, Hydra, WPScan, Impacket) and its own built-in engines into a single interactive session. You choose which modules to run — or fire them all at once with the full pentest option.

## Getting Started

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/afsh4ck/WSTG-Scan.git
    cd WSTG-Scan
    python3 -m venv venv && source venv/bin/activate
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Install optional tools for full coverage">
    ```bash
    sudo apt install -y nmap ffuf hydra whatweb seclists wpscan
    ```
  </Step>
  <Step title="Run your first scan">
    ```bash
    python3 wstg-scan.py --url https://example.com
    ```
  </Step>
  <Step title="Or use batch mode for multiple targets">
    ```bash
    python3 wstg-scan.py -L targets.txt --batch --output report
    ```
  </Step>
</Steps>

<Warning>
  WSTG-Scan is for **authorized security testing only**. Unauthorized use against systems you do not own or have explicit written permission to test is illegal. Always obtain written consent before scanning.
</Warning>
